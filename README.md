# Everyday Ibaadah Academy: platform prototype

A clickable prototype of the EDIA school platform for leadership review.

**Open it:** https://pythonistaabbey.github.io/edia-prototype/

- Pick any role on the sign-in page to explore its dashboard (no password needed).
- Switch between English and Arabic, and between light and dark mode, from the top bar.
- Everything is fictional sample data. Payments, emails, sign-in and integrations are simulated and labelled as such.
- Changes you make are kept only in your own browser. Use "Reset demo data" to start again.
